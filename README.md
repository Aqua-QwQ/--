# 从 Attention 到语音基础模型：论文阅读导引

这份导引用 12 篇论文串起一条学习路线：先理解注意力与 Transformer，再进入端到端语音识别，逐步学习对齐约束、声学建模，以及自监督和大规模监督训练。

从 **01 开始按编号阅读**。每篇都围绕一个问题展开，读完后留下能解释、能核查的笔记；涉及代码时，先做小实验，再考虑完整复现。全部原文和来源见 [论文索引](00-list/README.md)。

## 每篇论文怎么读？

建议分三遍完成，按理解程度推进，不设固定天数。

1. **建立轮廓。** 读摘要、引言、模型图和结论。在 `note/tmp.md` 写下：解决什么问题、采用什么方法、还有什么没看懂。
2. **拆解方法。** 沿输入到输出追踪数据流，标记核心公式与张量形状。先抓住关键模块，再回看细节；疑问记到具体章节或页码。
3. **核对证据。** 阅读实验设置、主结果与消融。记录结论对应的表格或页码，检查提升来自结构、数据、训练设置，还是多项变化共同作用。

整理 AI 笔记时，把原文证据写入 `note/论文名.ipynb`。自己的理解、AI 的解释和论文明确报告的结果要能区分；不确定的内容保留“待核实”，回到 PDF 检查。
